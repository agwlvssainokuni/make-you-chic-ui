Noto Sans JP / Noto Serif JP の woff2 ファイル(400/700ウェイトのみ使用、`@fontsource/noto-sans-jp` / `@fontsource/noto-serif-jp` の `japanese` サブセットから取得)を同梱しています。

html-demo/はNode.js不要・ビルド不要で直接ブラウザで開ける静的デモのため(FR6)、npmパッケージ経由の自己ホスティングができるReact版(`docs/integration-guide.md`参照)とは異なり、woff2の実ファイルをここに直接同梱しています。
