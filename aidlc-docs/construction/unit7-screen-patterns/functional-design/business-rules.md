# Business Rules — Unit 7: 画面パターン

## List View(Question 3 = A)

- フィルタバー: 名前/メールアドレスの部分一致テキスト検索(1つの検索ボックスで両方を対象)+ 役割(role)のSelect絞り込み。両条件はAND結合
- 一括操作バー: 1行以上選択時のみ表示。選択件数の表示 + 「削除」ボタンのみ
- 一括削除: 簡易確認Modal(Question 4 = A)

## Detail View

- ヘッダー: Avatar(name/avatarSrc)+ 名前 + 役割
- タブ構成: 「基本情報」(Description Listパターン、name/email/role)、「アクセス権限」(Table、tablePermissionsを表示専用で一覧)、「危険操作」(ユーザー削除)
- 危険操作タブのユーザー削除: 対象名確認テキスト入力式Modal(Question 4 = A)。入力値が対象ユーザーの`name`と完全一致した場合のみ削除ボタンを有効化する

## 編集Modal

- 新規作成/編集で同一Modalコンポーネントを使い回す(`mode: 'create' | 'edit'` propで初期値とタイトルを出し分け)
- `mode='create'`: 全フィールド空欄、タイトル「ユーザーを新規作成」
- `mode='edit'`: 対象ユーザーの値で初期化、タイトル「ユーザーを編集」
- フォームフィールド: 名前(必須)、メールアドレス(必須)、役割(Select)
- 保存: ローカルstateの配列を更新(新規作成は追加、編集は該当IDを更新)してModalを閉じる。バリデーションは必須項目の空チェックのみ(簡易)

## 削除確認Modalの使い分け(Question 4 = A、確定)

| 発生元                          | 種別                                                    |
| ------------------------------- | ------------------------------------------------------- |
| List Viewの行アクションの削除   | 簡易確認Modal(「削除しますか?」+ 削除/キャンセルボタン) |
| List Viewの一括操作バーの削除   | 簡易確認Modal(対象件数を表示)                           |
| Detail Viewの危険操作タブの削除 | 対象名確認テキスト入力式Modal                           |
